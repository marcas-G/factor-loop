架构约束（修复点）

  1. evidence 不经 agent：check_factor 内部 run_save，返回只 {failureLayer, summary}
  2. persist_factor 3 参数：内部 runLoad 组装，避免 agent 传复杂对象
  3. 质量失败可救：too_small/check_failed 带 diagnosis，quality_budget 重写因子
  4. dag_running 等 DAG：→ platform_timeout，timeout_budget=8 重 check 等
  5. 语义检索首选：semantic_search（CPU torch）> factor_search（FTS5）
