# Trading World Model — 5 品种 500ms 盘口环境

> **用途**:所有 cog agent 的共享参考。描述**客观市场机制**(参与者/事件/价格形成/品种环境),不描述系统当前库状态(算子/角度族不在世界模型里,避免限制发散)。
>
> **来源**:本地数据(data/factors.db: 5 品种 factor_ic_daily + factor intuition) + SHFE 规则 + 微观结构理论 + 跨品种联动研究。

## §1. 交易环境

### 数据结构(X 多源 → Y 单目标)

| 项 | 值 |
|---|---|
| X 特征 | **5 品种 × 主力/@1 = 10 列**:AG(白银)/CU(铜)/AU(黄金)/AL(铝)/NI(镍) |
| Y 目标 | **只 SHFE-AG**(未来 N 秒中价指数变动, N=1/5/10/60/300) |
| 数据频率 | **500ms snapshot**(唯一可观测频率) |
| 研究范式 | 用 5 品种的 500ms 盘口状态预测 AG 未来收益——**单品种 Y、多源 X 的跨品种监督学习** |

### 5 品种合约要素

| 品种 | 代码 | 合约单位 | 最小变动 | 夜盘收市 | 属性 | 涨跌停 |
|---|---|---|---|---|---|---|
| **AG 白银** | SHFE-AG | 15 kg/手 | 1 元/kg | **02:30** | 贵金属+工业双属性 | ±3% |
| **AU 黄金** | SHFE-AU | 1000 g/手 | 0.02 元/g | **02:30** | 纯避险/金融属性 | ±6% |
| **CU 铜** | SHFE-CU | 5 吨/手 | 10 元/吨 | 01:00 | 工业景气、信息效率最高 | ±6% |
| **AL 铝** | SHFE-AL | 5 吨/手 | 5 元/吨 | 01:00 | 工业 | ±6% |
| **NI 镍** | SHFE-NI | 1 吨/手 | 10 元/吨 | 01:00 | 波动最大(保证金 12%) | ±10% |

### 品种间差异对认知协议的影响

- **AG/AU 夜盘至 02:30**(与 COMEX 联动)，**CU/AL/NI 至 01:00**——01:00-02:30 只有 AG/AU 在场，跨品种信号在此窗口断缺
- NI 波动/保证金/涨跌停远大于其他——**同因子在不同品种的 IC 含义不同**（NI 的"极端波动"阈值应高于 AG）
- AG 同时具有贵金属（避险）和工业属性——**金银比/铜银比变化时 AG 的双重属性切换**
- 每品种都有主力/@1 两个合约——**跨月（主力↔@1）+ 跨品种（AG↔CU/AU/AL/NI）两套 lead-lag**

### 主力/次主力

主力合约 = 成交量+持仓量最大的近月；次主力(@1) = 第二活跃。两者间有套利联动（跨月价差回归）。

**日盘** 09:00-11:30(10:15-10:30 休)/ 13:30-15:00；**夜盘** 21:00 起（AG/AU 至 02:30，有色至 01:00）。

## §2. 参与者模型(核心)

四类角色在 500ms 盘口上博弈。**每个因子的可观测信号,本质是某一类参与者行为的留痕**。

### 2.1 知情大资金(hunter / 知情交易者)
- **行为**:隐蔽建仓(依托流动性掩护)、声东击西(跨品种对倒制造虚假信号)、关键位点火(触发散户跟风/止损)
- **留痕**:深层均匀挂单掩护意图、浅层虚挂诱导、大单连续冲击、跨合约同步异动
- **信息**:有私有信息(基本面/资金面/事件),预测价格方向
- **对应理论**:VPIN 的"有毒流"发出方 —— 做市商与他们交易承担逆向选择

### 2.2 做市商 / 被动流动性提供者
- **行为**:挂单(add)提供流动性赚价差、撤单(cancel)管理库存/逃离被冲击侧、护盘(薄弱位补挂)
- **留痕**:add/cancel 模式、spread 调整、被冲击侧定向撤单、报价迁移
- **风险**:**逆向选择风险**(被知情者吃单) —— 这是做市商行为的核心驱动
- **现状**:白银期货有做市商制度(已覆盖全品种),但散户也多 → 盘口是"做市防御 vs 知情冲击"的博弈场

### 2.3 散户 / 机械反应方
- **行为**:追涨杀跌、跟风、机械止损(触发级联)
- **留痕**:高波动下持仓激增(沿方向延续)、主动加单密集且撤单滞后、止损单集中于关键位
- **信息**:无私有信息,纯反应式 —— 是知情者的"猎物"

### 2.4 套保 / 跨期跨品种套利
- **行为**:跨月对冲(主力挂 bid + 次主力挂 ask)、跨品种对冲(金银比等)
- **留痕**:跨合约 lead-lag、主力方向前兆、价差回归
- **信息**:套利约束(无方向赌注,但留痕揭示主力意图)

## §3. 事件语义字典(字段 → 市场行为)

**这是 agent 读因子公式的第一层映射**。公式里的每个字段,对应一个市场行为/参与者留痕:

| 字段 / 数据角色 | 市场语义 | 谁的行为 | 信息含量 |
|---|---|---|---|
| `bid_size[i]` / `ask_size[i]`(BOOK_DEPTH) | 第 i 档**挂单量**=被动方/做市商**意愿强度** | 做市商/被动方 | 意图(可撤销) |
| `trade` price/qty(TRADE_PRICE/SIZE) | **主动成交**=aggressive 吃单 | 知情者/散户(方向性) | 行动(已落地) |
| `trade` side(TRADE_SIDE_EVENT) | 主动成交方向 | 方向性交易者 | 行动方向 |
| `cancel` level/qty/side | **撤单**=做市商撤销意愿 | 做市商 | 意图撤销(可能 spoof 揭示) |
| `add`(receive Order) | 挂单事件 | 做市商/被动方 | 意图 |
| OI 变化(OI_SERIES) | **持仓变化**=开仓/平仓(资金事件) | 全体(成交后形成) | 能量(非方向) |
| midprice / RETURN_SERIES | 价格中枢 / 收益 | 全体博弈结果 | 被测 Y 的基础 |
| spread(SPREAD) | 买一卖一价差=流动性/竞争度/毒性 | 做市商定价 | 逆向选择风险代理 |
| signed_flow(SIGNED_FLOW) | 方向流代理(已加工) | 方向性交易 | 方向 |
| total_volume / active_volume | 累计/主动成交总量 | 全体活跃度 | 活跃度(无方向) |

**核心区分**:`add`/`cancel`/`bid_size` = **意图**(可瞬间撤销,可能 spoof);`trade`/`Δoi` = **行动**(已落地,真实信息)。

## §4. 价格形成机制

### 4.1 短期价格驱动(OFI 视角)
- **限价单簿事件驱动**(非成交驱动):短期价格变动主要由 add/cancel/depth 变化(订单流不平衡 OFI)驱动,成交只是确认
- 净压力(bid 强 / ask 强)→ 短期价格方向
- 深档 OFI 比仅最优档 OFI 解释力更强(深档反映真实流动性结构)

### 4.2 突破与级联
- **做市商防御被击穿**:护盘薄弱位(TimeSeriesWeakPoint)、流动性真空、止损密集位被触及
- **止损级联**:止损单连锁触发 → 价格台阶式移动(op3 成交价连击的签名)
- **突破后运行持续性**:driver(thrust)冲击 response 后是否持续同向(op11 coherence 门控)

### 4.3 意图 vs 行动(核心识别判据)
- `add` = 意图,**可瞬间 cancel 失效**(spoof 虚挂诱导)
- `trade` = 行动,**落地真实信息**
- `Δoi` = 成交后形成的真持仓(比 add 干净)
- **识别真伪**:意图与行动背离 = spoof 被戳穿 / 知情者用虚假意图掩护真实方向
- 极值处撤单不平衡多为**事后补救**(知情冲击落地后做市商被动反应),真正前兆在中性量级微偏

### 4.4 价格冲击与流动性
- 价格冲击 ∝ 订单量 / 深度(Kyle lambda)
- 流动性陷阱(深度薄)→ 价格跳跃放大
- 做市商在波动率跳升后 50-200ms 调整报价 → 500ms 快照能捕捉到后果

## §5. 盘口结构语义

| 结构 | 语义 |
|---|---|
| **深度分布形状**(5 档 size 向量) | 做市商意愿强度 + 支撑/阻力 |
| 熵突增 | 分散挂单**掩饰冲击**(知情者隐蔽) |
| 熵骤降 | 大单堆积**真实意图**(单向护盘/冲击) |
| 凹凸/偏度/重心 | 流动性曲线形态 |
| 最优档 | 即时竞争(最敏感) |
| spread | 流动性/竞争度/毒性(逆向选择风险) |
| 深档 vs 浅档 | 厚度/脆弱性(深档薄 = 易被击穿) |
| imb 向量(非标量) | N 档分布的矩(重心/分散度/方向熵),逃出标量族饱和 |

## §6. 时间结构

- **日内**:开盘集合竞价(意愿集中)→ 连续竞价(信息驱动)→ 收盘;夜盘(海外联动,信息密集)
- **事件维度**:突发(单点大跳,信息强)vs 持续累积(趋势,信息渐显)—— 同一瞬时值,形成过程不同则预测含义不同
- **耗散动力学**:冲击 → 盘口恢复(做市商补单/撤单)的过程,有相位结构
- **regime 门控**:波动率/流动性状态决定信号可靠性
  - 高波动 → 放大散户行为(可利用也可噪声)
  - 低流动 → spike 多是噪声/虚挂
  - regime 转换历史(activation trajectory)比当前 regime 值更重要

### 2.5 跨品种联动(5 品种间的传导机制)

沪银（AG）是本系统的 **Y 目标**，但 X 含 5 品种。理解品种间联动是拆"跨品种 X → AG Y"假设的基础。

**相关性**(研究实证):
- 沪金-沪银 ~56%；沪银-沪铜 ~45%；金银比与铜价负相关可达 -0.8
- 有色品种（CU/AL/NI）间相关性更高（工业属性同源）

**传导链**(GARCH/Granger 实证):
- **沪银是传导中枢**:对沪金/沪铜横向冲击 0.7%/0.8%（最强）
- 信息效率排序:沪铜 > 沪银 > 沪金（铜对信息反应最快）
- 传导方向:沪铜→沪金→沪银（铜领先）；但沪银自身的波动冲击传导范围最广

**比值指标的经济周期含义**(影响 regime 判断):
- **金银比**(AU/AG)高 → 避险情绪浓、降息尾声；回落 → 工业需求复苏（AG 工业属性凸显）
- **铜金比**(CU/AU)低 → 滞胀/衰退；高 → 复苏/过热。铜金比领先 10Y 美债收益率
- **铜银比**(CU/AG)变化反映工业 vs 贵金属属性的相对切换

**行情顺序**(本轮实证):黄金先启动 → 金银比极端 → 白银逼空 → 铜铝跟涨。贵金属领先工业金属。

**对因子审查的含义**:
- 因子若用 CU/AU 的 X 列，它在测"跨品种传导/lead-lag"——铜领先是信息源，银是接收端
- 金银比/铜金比的变化本身是 regime 信号——可作门控
- AG 作为"双重属性"品种，其盘口行为在避险 regime 和工业 regime 下可能不同

| 边界 | 含义 | 不能做 |
|---|---|---|
| **OBS001 ORDER_IDENTITY** | Feed::Order/Cancel 无 order_id/ref | 精确配对 add→cancel、跟踪单笔挂单 lifecycle、构造配对关系实体 |
| TRUE_EVENT_TIME | 500ms 是快照时间,非撮合前真实事件戳 | 亚 500ms 精度的时间排序 |
| REAL_INTERVENTION | 央行/政策/外生事件不在行情内 | 直接观测外生信息 |

**能做的近似**(诚实标注,不作正式 operator 证据):
- 事件类型 + level/qty/side + 500ms 时序(可观测)
- (level,qty,side,time) 启发式配对(不唯一,同档同量多笔错配)
- 粗粒度事件归因(用 add/trade 流的相对模式,非精确身份)

## §8. 关键判据(从 323 lessons 提炼的负面知识)

1. **意图 vs 行动必须分开验证**:add spike 只是意图(可 spoof),Δoi/trade 才是落地;拆单边验证就退化为单边 OFI
2. **新息而非水平值**:去自相关后的 surprise 才有信息(水平值已被榨干)
3. **OI 做能量不做方向**:OI 符号方向不稳(反复死因),只能做能量/事件
4. **事后痕迹 vs 前兆**:极值处信号多为事后态(做市商补救),前兆在中性量级微偏
5. **regime 门控是核心降噪**:低流动期 spike 多噪声,只在高流动 regime 触发
6. **跨品种维度**:X 含 5 品种——铜领先(信息效率最高)、银是传导中枢、金银比/铜金比是 regime 信号。跨品种 lead-lag 是 alpha 维度(§2.5)
7. **同源冗余是死因**:pearson > 0.9 的因子同源,需对称化/换基底

## §9. agent 使用指引

### assumption extractor 读因子时(关键升级):
1. **字段映射**:公式里的 `bid_size`/`trade`/`cancel`/`OI` 对应 §3 的市场语义(不是抽象变量)。`bid_size[0]` = 最优档做市商挂单意愿,不是"变量 x"。
2. **机制理解**:这个因子在测**哪个参与者的哪种行为**?(§2)在**哪个市场过程**里?(§4)
3. **假设抽取**:在这个机制下,因子把什么**过程/结构/关系**压掉了?(不是"坐标")
   - 浅假设(句法):"压掉 depth 坐标" → N3 接得住
   - 深假设(机制):"压掉压力来源(做市商被动调整 vs 方向交易者主动冲击)" → 指向事件归因,N3 未必接得住
4. **世界模型一致性**:抽出的假设是否符合 §2-§8?是否触到"意图 vs 行动"/"新息"/"OI 能量"/"regime 门控"这些核心判据?

### adjudicator 判证据时:
- evidence 是否触到 §4 的某个机制(意图 vs 行动 / 突破级联 / 耗散动力学)?
- 还是只触到 §5 的盘口结构统计(落在 N3)?

### minimal-repair 判深度时:
- N3 能否**语义对应** §4 的机制?(不是"能不能算 autocorrelation",而是"autocorrelation 是否真表达'压力耗散相位'")
- 区分:**统计描述**(N3 能)vs **对象构造/事件归因**(N3 不能,需新 measurement object)

## §10. 一句话世界模型

> 5 品种(AG银/AU金/CU铜/AL铝/NI镍)× 主力/@1 的 500ms 盘口 → 预测 AG 未来收益。四类参与者(知情/做市商/散户/套保)在订单簿博弈,意图(挂单)与行动(成交)背离是识别真伪的核心判据。铜领先(信息效率最高)、银是传导中枢、金银比/铜金比是 regime 信号。价格形成 = 做市商防御被击穿 → 止损级联。前兆在中性量级微偏,极值处多为事后态。
