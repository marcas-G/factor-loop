# Reseed — 新基底再播种

触发：research-loop 选中一个因子后，先调 `mcp__quant-mcp__factor_saturation_status {xname}`。

只有 `saturated == true` 才进入本 skill；否则返回 `{ok: false, reason: "branch_not_saturated"}`，由 research-loop 继续原认知协议深挖。

## 目标

不要继续深挖当前分支，也不要生成复杂因子。对选中因子做**换根**：保留它的 measurement shape，把测量结构落到一个与旧根属于不同研究对象的现实过程上，产出浅层、独立、可继续深挖的 Measurement Seed。

## 六步协议

每一步都是「反问 + 强约束」。禁止列候选、禁止比较多个方案、禁止给字段菜单。

### Step 1 · 去名化（只留测量骨架）

先把原因子彻底去名化，只留下测量骨架。

反问：

> 删除所有字段名、因子名、经济概念和原因子解释后，这个表达式还保留了什么最小测量结构？

约束：

- 禁止出现 OI、仓位、成交量、盘口、价格等任何实体名。
- 禁止出现原因子的经济语义。
- 必须输出纯结构描述，例如：

```text
某个随事件更新的可累积状态 X
    ↓
局部增量 |ΔX|
    ↓
在某种活动尺度内聚合
    ↓
测量这些增量在局部区间中的集中程度
```

这一阶段保留的是 **measurement shape**，不是原因子的语义。

### Step 2 · 载体约束（只提取性质，不找载体）

只提取“新载体必须满足什么性质”，绝不问有哪些载体。

反问：

> 如果要让上面的测量结构在另一个完全不同的研究对象上仍然成立，新对象至少必须具备哪些可操作性质？

约束：

- 只能回答性质，禁止回答任何具体市场实体。
- 输出格式例如：

```text
能随事件发生变化；
可以定义局部增量；
增量可能呈现稀疏或爆发结构；
存在与自身活动一致的聚合尺度。
```

这一步得到的是**载体约束**，不是候选字段集。

### Step 3 · 换根（一次只选一个）

这是最关键的一步。

反问：

> 现在禁止使用原因子的根概念、它的同义词、近义代理和原字段。也禁止查看可用字段列表。
> 给定刚才得到的测量骨架和载体约束，在真实市场过程中，选择一个与旧根属于不同研究对象的现实过程，使该测量骨架可以自然落在它上面。

强约束：

- 不得给候选列表，不得比较多个方案，不得说“可以考虑 A/B/C”。
- 必须直接决定一个。
- 判断标准不是“哪个字段可以替换 X”，而是**哪一种不同的现实过程天然具有 X 所需要的结构性质**。
- 如果想不到满足条件的对象，返回失败，不得硬凑。

示例：从匿名结构「可累积状态 → 局部增量 → 爆发 → 集中度」跳到「成交活动过程」，而不是因为看到 totalVolume 才想到成交量。

### Step 4 · 破坏配套结构（只改必要部分）

选中新载体以后，再破坏原来的配套结构。

反问：

> 如果把测量载体替换成这个新现实过程，原因子继承下来的时间坐标、事件定义和聚合方式中，哪些已经失去自然语义？

强约束：

- 只修改为使新载体自洽所必需的部分；不得为了追求新颖继续增加结构。
- 例如新载体 = 成交活动，那么“Book 事件 200 样本”未必还是最自然的尺度。
- 对“成交活动”反问：什么尺度才是它自身的自然进度？→ 直接判断为 volume clock。
- 仍然不是“时间窗、成交量窗、事件窗你选哪个？”——必须直接判断。

### Step 5 · 数据绑定（语义 → 数据）

直到这里才允许碰数据字段。

反问：

> 要观测刚才已经确定的新现实过程和聚合结构，当前数据中最直接的最小 observable 是什么？

强约束：

- 只绑定一个最直接实现；禁止列候选字段。
- 如果当前数据无法直接实现，返回 `ungrounded_new_root`，不得换一个更方便的语义解释迁就数据。
- 顺序必须是「语义 → 数据」：先有现实过程，再绑定 `totalVolume`。

### Step 6 · 语义回填 + 脱根测试

最后做语义回填，并且进行“脱根测试”。

反问：

> 完全根据新的载体、时间尺度和测量结构，重新回答：
> 新因子最基本在研究什么对象？
> 它把市场区分成什么不同状态？
> 它成立依赖什么最小世界模型？

强约束：

- 回答中禁止出现原因子根概念及其同义表达。
- 例如输出：

```text
新根：成交活动的时间组织结构
Measurement：成交活动是否集中在少数局部活动阶段
World model：成交过程并非均匀连续流，而可能由背景交易与局部活动脉冲共同组成。
```

然后强制最后一个反问：

> 如果不知道原因子曾经研究 OI/仓位，新因子是否仍然可以从零开始被完整定义？

- 如果不能：`reject: root_not_detached`，重新回 Step 3。
- 如果可以：`root_shift = true`，产出候选。

## 输出

返回单个候选 factor 对象：

```json
{
  "name": "<简短类名>",
  "formula": "<最小直接实现，禁止复杂算子链和纯后处理>",
  "intuition": "<新根对象 + 测量操作 + A/B 区别，纯中文，不得出现旧根概念>",
  "tags": ["reseed", "<新根>", "<操作>"],
  "params": {},
  "categories": ["AG"],
  "reseed_from": "<原因子 xname>",
  "measurement_object": "<新根>",
  "operation": "<T_S>",
  "distinction": "A/B 在 ___ 相同，但在该测量上不同",
  "root_shift": true
}
```

不在这里继续研究，交回 research-loop Step 2 走 write-factor → run-factor → assess → persist，血缘边记为 `reseed`。

## 禁止项

- 改窗口、改参数（作为唯一变换）
- rank / zscore / winsorize / 标准化（作为核心操作）
- 简单线性组合或直接复用原复杂因子
- 使用超过两个测量操作
- 沿基底做第二层、第三层假设攻击
- 为了成立随意引入额外实体
- 直接预测未来收益
- 给现有概念换新名字
- 列候选字段 / 比较多个方案 / “可以考虑 A/B/C”
- 去名化阶段出现实体名
- 先看字段再补语义（必须是语义 → 数据）
- 回填阶段出现旧根概念
