# MR Description Template

```markdown
## Summary

One or two sentences explaining what this MR does and why.

## Changes

- <type>(<scope>): <change description 1>
- <type>(<scope>): <change description 2>
- ...

## Details

(Optional) Explain complex changes, trade-offs, or anything reviewers should know.
```

## Rules

- Each item in Changes follows `<type>(<scope>): <description>`
- Write in imperative mood
- Write in the same language as the commit messages (Chinese or English)
