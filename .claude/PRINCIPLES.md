# 因子挖掘指导思想

## 研究方法论
1. 先复现经典，确认信号存在再创新
2. 最小可信号：先裸信号，再变换/组合
3. 递进路径：单因子 → 时序变换 → 组合

## 信号偏好
- 微观结构 > 量价关系
- 物理意义清晰 > 纯统计显著
- 简洁（参数少）> 复杂

## 避免的陷阱
- 过拟合：单因子参数 ≤ 3
- 未来函数：所有计算只用 t-1 及之前数据
- 复杂变换：单因子变换层数 ≤ 2

## "好因子" 标准（按优先级）
1. 物理可解释
2. IC > 0.05 且跨时段稳定
3. 与已有因子相关性 < 0.7
4. 多品种普适

## 当前研究方向
- 优先：订单簿不平衡的多档聚合
- 次优：成交-撤单交互
