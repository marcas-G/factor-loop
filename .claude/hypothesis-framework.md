# Tick 因子本质分析框架

> 因子 = 对「未来净订单流的不平衡,由什么生成」的可证伪假设。
> **反推 + 三道门槛**:① 赚钱闭环(凭什么持续赚,§2)→ ② 因果链(谁、为什么、怎么做,含单间隔微观 E,§3)→ ③ 复杂度可控(§6)。过不了任一道门的拒收。

---

## 1. 第一性原理:为什么必须反推

价格变化的根本原因只有一个:**净订单流不平衡**。`未来收益 = g(未来净订单流)`。

所以因子有效的关键是:**它携带了「未来净订单流」的信息**。而信息不能凭空产生——X 携带 Y 的信息,通常意味着两者有**因果或共同原因**。说不出可解释机制的相关,过拟合风险高、易衰减。

两条路径的根本差异:

| | 正推(特征工程) | 反推(本质分析) |
|---|---|---|
| 起点 | 盘口有哪些特征 | 未来订单流不平衡由什么生成 |
| 问的问题 | "这个组合有效吗?" | "它**凭什么**有效?凭什么**持续**?" |
| 产物 | 坐标枚举 + IC 扫描 | 赚钱闭环 + 因果链 + 盘口签名 |
| 风险 | 高(易过拟合、撞常识) | 低(共同原因 + 闭环明确) |

**现有「事件源×度量×窗口」框架是正推的**——它鼓励枚举坐标组合,所以自然产出低级假设。本框架把它降为实现工具箱(§5),骨架改为反推:先过赚钱闭环(§2),再走因果链(§3),再钉到单间隔事件(§4)。

## 2. 赚钱闭环(第一道门槛,可持续性根基)

**为什么闭环是根基**:零和市场里,任何能持续赚钱的行为,必须有清晰的利润来源——赚谁的钱、什么性质的钱。说不清利润来源的"手法",签名不会持续,预测力必然衰减。**这解释了大量 imbalance/spoof 类因子短期 IC 好看、很快失效:它们没有闭环根基。** 闭环 = 假设可持续性的证明。

它在因果链之上,是第一道门槛:先过"赚谁的什么钱",再谈机制。

### 利润来源 L1-L5(候选清单,归纳性、非穷尽、不互斥)

> ⚠️ 这**不是权威分类**,是我归纳的常见候选,辅助思考用。**关键要求是"假设必须能回答'赚谁的什么钱'",不强求归入某 L**。互斥性差(知情者也赚别人的机械反应,L3/L1 重叠);遇表外的(纯套利/均值回归、操纵 spoof/layering、交割/限仓等结构事件)就单列,别硬塞。

| L | 谁赚 | 赚谁 | 闭环约束(何时断裂) | 500ms |
|---|---|---|---|---|
| **L1 别人的机械反应** | hunter/点火者 | 止损/强平/追涨者 | 机械反应存在 ∧ 收益 > 推价成本 | ✓ |
| **L2 流动性补偿** | 做市商 | 价差 + 返佣 | 价差收益 > 逆向选择损失 | ✓ |
| **L3 信息优势** | 知情者 | 信息滞后者 | 信息优势 > 获取成本 ∧ 未泄露 | ✓ |
| **L4 速度优势** | 高频 | 慢方 | 速度差存在 | ✗ 失效 |
| **L5 风险溢价** | 持仓者 | 风险补偿 | 承担风险有补偿 | △ 短周期几近为零 |

> L 决定可持续性。500ms 把 L4 排除、L5 几近于无。编号只为引用便利,**不暗示穷尽**。

### 赚钱型 vs 执行型手法 + 闭合判据(关键)

- **赚钱型**(做市/点火/套利/stop hunting):闭环自洽,直接生成假设。
- **执行型**(iceberg/TWAP/被动吸纳):本身不赚钱,服务于更大的 L3 闭环。**必须追溯到背后的利润来源**,否则闭环不全。

**闭合判据(硬门槛)**:闭环必须落到 L1-L5 的某个利润来源——"**赚谁的什么钱**"必须能回答。停在"XX 方意图 / XX 方代理 / XX 方行为"的,判**闭环未闭合**,拒收。

| 闭合 ✓ | 未闭合 ✗ |
|---|---|
| 赚被迫强平者的钱(L1) | 挂单方意图看多(意图,没说赚谁) |
| 做市商赚价差、防御毒性(L2) | 做市商防御方向(行为,没说赚什么) |
| 知情者赚信息滞后者(L3) | 知情者建仓(行为,信息源头没说) |

判别问句:把"为什么有效"反复追问,最终必须落到"赚某方某类钱";落到"因为 XX 方这么做了"就停 = 未闭合。我之前"被动吸纳""挂单意图代理"都死在这。

### 闭环 5 问(门槛,每个假设必答)

1. **谁在赚?**
2. **赚谁的、哪类钱(L1-L5)?**
3. **闭环约束**:什么条件下闭环断裂(= 失效)?
4. **闭环逼出的操作**:为闭环他必须怎么做(签名)?
5. **怎么搭便车**:识别闭环进行中 → 闭环下一步 → 价格?

答不出 1-3 的,判"无闭环根基",即使短期 IC 好也标红。

### 范例:stop hunting(L1 闭环)

| 问 | 答 |
|---|---|
| ① 谁赚 | 资金雄厚的 hunter |
| ② 赚谁/哪类 | 关键位止损单持有者,**L1** |
| ③ 约束 | 止损聚集足够 ∧ 推价成本 < 级联收益 ∧ 能退出 |
| ④ 操作 | hunter 主动连续同向吃单,推价触穿关键位 → 止损级联 |
| ⑤ 搭便车 | 识别"推价逼近+触穿" → 跟级联 → 级联耗尽前退出 |

**闭环约束直接给消歧**:触穿后**必须出现级联**(验证止损存在);无级联 = 关键位没止损 = 不是 hunting,信号作废。理论消歧,不是硬调阈值。

## 3. 因果链模板(第二道门槛,标准化)

过闭环之后,填满这条链的七节,缺一节即判不完整:

```
① 行动者   谁(赚方)
② 动机     赚谁的什么钱(L1-L5)+ 闭环约束          ← 接 §2
③ 触发     什么条件下他会行动                 ← 含上下文 C(历史/状态量)
④ 行动     他做什么(下单/撤单/移档/…)
⑤ 痕迹 E   t-1→t **可分解的微观事件**:具体叙述"这 500ms 里谁对哪档
          做了什么",用分量(add_i/cancel_i/各档 price·size Δ)组合;
          禁用聚合净量(Δsize/Δmid 单独)充当 E——净量掩盖分解
          (净+10 可能是 加15撤5 或 加12撤10,含义不同)   ← 假设对象
⑥ 反推     E ∧ C → 预测对象(方向/分布/状态/路径)
⑦ 失效     闭环约束(§2 ③)何时断裂
```

**范例:做市商毒性逃离(L2 闭环 → 因果链)**

| 节 | 内容 |
|---|---|
| ① 行动者 | 做市商(持续在场、靠推断吃饭的理性博弈方) |
| ② 动机 | **L2 流动性补偿**——赚价差,但要控逆向选择损失;从订单流推断毒性后定向防御 |
| ③ 触发 | 某侧订单流毒性推断上升(该侧成交密集且单向) |
| ④ 行动 | 被推断为知情方来袭的那侧**定向防御**:撤薄 best 档 + 扩该侧半价差,对侧深度不动 |
| ⑤ 痕迹 | ask0:`cancel_0` 加大 ∧ `add_0` 未跟上(撤主导,非成交消耗)∧ `Δask0_price ≥ 0`(撤后价位不降)∧ 对侧 bid0:`cancel_0` 未加大(非对称,非整体撤退) |
| ⑥ 反推 | 防御方向 = 做市商推断的知情方向 → 跟随逃离侧。预测对象:方向 |
| ⑦ 失效 | 做市商撤离/算法同质化(同样防御→信号磨平);知情者改用不触发防御的策略 |

**对比(spoof 背离,过不了闭环)**:① 操纵者 ② L1 获利 ③ 想诱导 ④ 挂大单后撤 ⑤ 撤单↑∧成交→ ⑥ 反向 ⑦ 被监管。→ 闭环约束(诱导能否成功、成本收益)**没说**,因果链停在 ④⑤ 表面——闭环不全,标红。

**判据(深度)**:假设质量 = 利润来源 L 多明确 + 闭环约束多硬 + 因果链 ②③⑦ 多深。

**判据(精度)**:E 要能像"bid0 加15撤5、ask0 加3撤12"这样**具体叙述**——落到分量,说出"这个间隔里到底发生了什么"。只能说"size 变了""mid 动了""成交大了"这种聚合描述的,判精度不够,拒收(那是窗口策略/特征工程,不是 tick 级事件假设)。

## 4. 假设登记模板(三道门槛总纲)

假设登记到 `state.factors[].hypothesis`(brainstorm 拼 `intuition` + `diff_check` + `coord_usage`),经 `persist_idea` / `persist_candidates` 写 `ideas` 表 + state;**必须先于 IC 写**(先验性)。

```
利润来源:  L1/L2/L3/L5(L4 在 500ms 失效;可组合)     ← 第一道门槛
闭环 5 问: ①谁赚 → ②赚谁什么/约束 → ④操作签名 → ⑤搭便车
因果链:    ①行动者 → ②动机 → ③触发 → ④行动 → ⑤痕迹E → ⑥反推 → ⑦失效
事件 E:    t-1→t 可分解微观事件,落到 add/cancel/各档分量        ← 假设对象
上下文 C:  分类条件,用窗口/历史量(窗口 + 时钟)              ← 非假设对象
预测对象:  E ∧ C → 方向 / 分布 / 状态 / 路径(horizon h)
坐标数 n:  1 / 2-3 / ≥4 或跨域(过拟合风险代理)
失效条件:  闭环约束断裂 + 因果链 ⑦
先验性:   假设写于 IC 之前 [Y/N]
```

**门槛规则(三道,任一不过拒收)**——本节是总纲,§2/§3/§6 是各道展开:
1. **① 闭环闭合**(§2):利润来源 + 闭环 5 问(尤其 ②③)必填且先验;**必须闭合到利润来源,停在意图/代理/行为的判未闭合**(§2 闭合判据)。
2. **② 因果链完整(含微观 E)**(§3):七节填满;⑤ E 必须是**可分解微观事件**(落到 add/cancel/各档分量),禁用聚合净量充当——拿不出微观 E 的判"窗口策略/特征工程越界"。
3. **③ 复杂度可控**(§6):n≥2(复合/结构)额外要求机制逻辑可复述(不能算子硬拼)。

三道门槛把 spoof 类表面签名、被动吸纳/挂单意图类**未闭合闭环**、聚合净量的**伪 tick 假设**、跨多 tick 的模式策略、纯特征枚举一并挡在门外。

## 5. 盘口签名工具箱(实现层 = 旧坐标)

因果链 ⑤「痕迹 E」落地用的工具。**这些不是假设的起点,是被闭环和因果链选中的实现手段**。

### 5.1 可观测边界(诚实先行)

**数据**:`BookSnapshotInfo` 盘口快照,每合约 46 列 = 5档×(price/size/add/cancel)×bid&ask + 6 全局(`open_interest` `total_volume` `turnover` `last_trade_price` `last_trade_size` `mid_price`)。

- **标签 Y**:仅 `SHFE-AG` 主力,horizon `{1,5,10,60,300}`s,Y = 未来 N 秒 mid 收益。
- **快照频率**:上期所 500ms 定频(L1/L2 同),时间分辨率 = 2Hz。实测 dt p50≈0.501s、93% 在 ±50ms;dt>1s(~5%)为集合竞价/小节休息/停盘恢复。
- **三缺陷**:

| 缺陷 | 影响 | 替代/边界 |
|---|---|---|
| `last_trade_size` 全 0 | 单笔量级事件不可用 | 用 `Δtotal_volume` |
| 离线无 Trade feed | 无主动买卖方向 | 方向用 imbalance/加撤流/构造量代理;实盘 `receive(Trade)` 才有真方向 |
| `@1` 语义待确认 | 次月/夜盘不明 | 跨合约类因子先标注 |

### 5.2 构造量分层(痕迹可以是高阶量)

```
L0 字段 → L1a 原语事件(字段差分) → L1b 构造观测量(统计才可见) → L2 复合(逻辑算子) → L3 结构(跨域)
```

**L1a 原语事件源**(字段直接可见,两 tick 间的变化):

| 类 | 编号 | 事件 | 关键可观测量 |
|---|---|---|---|
| 价格 | A1-A4 | mid/best/成交价/多档价位移动 | `Δmid`, `Δbid0_p`, `Δask0_p`, `Δlast_trade_price` |
| 库存 | B1-B4 | 档位 size 变化、imbalance、深度结构 | `Δsize_i`, `Δlog((1+Σw·bid)/(1+Σw·ask))` |
| 加撤流 ⭐ | C1-C4 | 加单/撤单/净流/加撤失衡 | `add_i`, `cancel_i`, `(bid_add−bid_cancel)` vs `(ask_add−ask_cancel)` |
| 成交 | D1-D4 | 周期成交量/额、成交-挂单比、爆发 | `Δtotal_volume`, `Δturnover` |
| 持仓 | E1-E2 | OI 变化 | `Δopen_interest` |
| 时间 | F1-F2 | 快照间隔、频率 regime | `dt`, dt 聚类 |

**L1b 构造观测量**(字段里没有,需统计估计;本身可再事件化):

| 族 | 构造量 | 统计手段 | 可假设的现象 |
|---|---|---|---|
| 波动率 | RV / GK | 价格积分 | 压缩→爆发 |
| 价格冲击 | Kyle λ / Amihud | 回归 `Δp~Δv` | 敏感度突变=流动性枯竭 |
| 毒性 | VPIN | 成交 bucket+Δp | 毒性积聚 |
| 记忆 | Hurst / OU τ | R/S、OU 拟合 | 动量↔反转切换 |
| 聚类 | Hawkes λ/τ | 点过程拟合 | 激励衰减 |
| 分布 | 偏度/峰度/熵 | 矩估计 | 形态切换 |
| 均衡 | 协整残差/基差 | 协整回归 | 均值回归 |
| 状态 | regime/拓扑态 | HMM/聚类/持久同调 | 状态切换 |
| 时频/状态 | 小波尺度能量/谱质心/Kalman 隐含价/CCF lead-lag/coherence | 小波/FFT/Kalman/互相关 | 多尺度动量、信息流向、价格发现噪声 |

**DSP 工具筛选**(fs=2Hz、强非平稳约束;产出须锚回利润来源,锚不住即黑箱):

| 评级 | 工具 | 锚定的利润来源 |
|---|---|---|
| 高 | 互相关 CCF → lead-lag | L3 信息传导 |
| 高 | Kalman/状态空间 → 隐含均衡价+残差 | L3 价格发现噪声 |
| 中高 | 小波多尺度 → 尺度能量 | L5 状态惯性 |
| 中 | coherence → 频域跨合约同步 | L3 共振 |
| 中 | 低通滤波趋势分离 | L2/L5 趋势 vs 噪声 |
| ⚠️ | Hilbert 瞬时相位 / 格兰杰因果 | 易过拟合、参数多 |
| ✗ | 直接 FFT 系数 | 非平稳下无意义 |

### 5.3 度量 M / 窗口 W / 时钟 / 组合算子

**度量 M**:M1 幅度 / M2 方向 / M3 z-score / M4 比率 / M5 分位 / M6 多档加权 / M7 对数失衡 / M8 阈值触发 / M9 高阶矩熵 / M10 密度归一(`量/切片事件数`)。

**窗口 W**:W1 即时 / W2 滚动 `{10,50,200}` / W3 EWMA / W4 累积净流 / W5 频率计数。

**时钟**(500ms 定频下):时间窗 ≈ 事件窗(1 快照≈500ms,等价);**真正有区分度的是成交量窗(volume bar)和信息窗**,自动消除密度差异。

**组合算子 L2**:gate(A 在 B 态下才有效)/ confirm(同向印证)/ contradict(B 反向衰减)/ diverge(背离,A↑∧B→)/ cohere(共振)/ lead-lag / rebalance(再分布,A 减 B 增、总量守恒)。

**结构 L3 + 条件 G**:R 跨合约 / T 跨 horizon / 时段切换;G 条件(因子在特定 regime/方向切片下才成立,横切各层)。

### 5.4 密度归一(跨切片可比)

500ms 定频下 dt 近恒定,密度差异来自**切片内事件数**(一个切片成交 1000 手 vs 0 手),非 dt。归一用 M10(按切片事件数)或成交量/信息时钟;时间窗与事件窗在此数据等价。特殊长 dt 切片(~5%,集合竞价/小节休息)是状态切换事件,单独处理。

## 6. 复杂度与过拟合

坐标数 n 是过拟合代理:1 原子 / 2-3 复合 / ≥4或跨域 结构。

- n 越高,自由度越大,n≥2 必须有可复述的闭环+机制逻辑(因果链 ②③)。
- DSP/构造量类因子天然 n 偏高,门槛更严。
- 这道防线 + §2 闭环 + §4 三道门槛,层层过滤。
