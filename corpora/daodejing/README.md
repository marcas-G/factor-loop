# 道德经 / Dao De Jing（章节级语料）

本目录为 Corpus Autoloop 首个真实语料源，默认以每个**完整章节**作为一个初始 SourceUnit，不对“与量化是否相关”进行预筛选。

## 版本和内容边界

- 作品：`道德经`（王弼本，传统章序；道经 1–37，德经 38–81）。
- 原文总计 81 章，已固定于 `parts/001-012.json` 等七个文件中（最后一份 `073-081.json`）。
- 公开底本：中文维基文库 `https://zh.wikisource.org/wiki/道德經_(王弼本)`。
- 机器获取的章节原文源：`https://github.com/joechiboo/laozi-reader/tree/main/data/chapters`，提取其中每章的 `text` 原文字段。原来源仓库注明王弼本、原文为公有领域；其现代译文、注解、章节摘要、关键词**未复制**。
- 原文本身属于公有领域；整理标点和不同传本存在版本差异。请按每一章 `source_file` 追溯，不要把当前标点或一个传本假定成唯一古籍定本。
- `source_status=draft` 表示来源仓库的该章现代整理/注释尚未最终人工审核。我们仅使用经文文本，并不依据其现代解释直接生成研究证据。

## 数据结构

每条记录字段：`unit_id`、`chapter`、`part`、`title`、`text`、`source_file`、`source_status`。

`core/corpus_autoloop/corpus.py` 在读取时检查：
1. 81 个章次必须完整、无重复且按 1–81 可排序；
2. 每章非空、`unit_id` 与章节来源路径一致；
3. 为原文计算 SHA-256 指纹。初始化研究数据库后，原文发生变更会被拒绝，避免研究对象在实验后被悄悄替换。

下一本书可用同样的 SourceUnit 模型扩充，但目前代码刻意只注册《道德经》的 81 章。没有在书中发现金融证据，也没有因子表现的数据。
